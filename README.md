# 🦖 Dinosaur Game

A simple 2D endless runner game built using **vanilla JavaScript**, **HTML5 Canvas**, and **CSS**. Jump over obstacles, avoid cacti, and survive as long as you can!

![screenshot](screenshot.png) <!-- Optional: Replace with actual screenshot if available -->

---

## 🎮 Gameplay

- Press `Space` or `Arrow Up` to make the dinosaur jump.
- Avoid hitting the cacti — one hit and the game ends.
- The longer you survive, the faster the game gets.

---

## 🚀 Features

- Built with pure JavaScript (no frameworks or libraries)
- Smooth animations using `requestAnimationFrame`
- Pixel-style dinosaur and obstacles
- Score counter
- Game over screen with restart option

---

## 🛠️ Technologies Used

- **HTML5 Canvas** for drawing
- **JavaScript** for game logic
- **CSS** for layout and style
